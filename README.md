#  Stock Price Prediction

##  Project Overview
This project predicts future stock prices using historical stock market data and Machine Learning techniques. It performs data preprocessing, exploratory data analysis, model training, and prediction to forecast stock price trends.

##  Features
- Historical stock price analysis
- Data visualization
- Stock price prediction using Machine Learning
- Performance evaluation using regression metrics
- Google Colab implementation

##  Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

##  Dataset
The dataset contains historical stock market data, including:
- Open Price
- High Price
- Low Price
- Close Price
- Trading Volume

##  Workflow
1. Load historical stock data
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Train the Linear Regression model
5. Predict future stock prices
6. Evaluate model performance

##  Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

##  Results
The model predicts stock prices using historical trends and demonstrates reliable performance based on regression evaluation metrics.

##  How to Run
1. Clone or download this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Install the required libraries.
4. Run all cells.
